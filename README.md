## Rules: 
- each player has 3 moves per turn
- a move can be:
 - Raising the heigh of an unnocupied grid cell
 - moving a piece by one cell in one of 4 directions, as long as the destination's height different is less than or equal to 1
 - kill a neighbouring piece whose cell's height is lower by 1
- the game ends when a player can't make any more moves
